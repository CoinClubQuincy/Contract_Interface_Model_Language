# Conformance vectors

Plain JSON, so an implementation in any language can use them. They are generated by `scripts/generate-vectors.ts` and committed.

| Path | Contents |
|---|---|
| `vectors/valid/*.json` | `{ description, document }`. A conforming validator accepts `document`. |
| `vectors/invalid/*.json` | `{ description, expect, document }`. A conforming validator rejects `document` and reports every code in `expect`. It may report others too. |
| `vectors/canonical.json` | `{ cases: [{ name, input, expected }] }`. Canonicalizing the JSON text in `input` under RFC 8785 gives exactly `expected`. |

Vectors cover the document itself, with no network or chain. Runtime behaviour is specified in [spec/ciml.md](../spec/ciml.md) and [spec/iml.md](../spec/iml.md).
