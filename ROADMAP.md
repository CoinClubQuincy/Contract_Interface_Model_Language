# Roadmap

Plans, not promises. Open an issue if something here matters to you.

**Next**

- Publish the packages to npm.
- A precompiled validator, so pages do not need `unsafe-eval`.
- Try ERC-7730 exports on real wallets and hardware devices.
- An independent security review.

**Later**

- Signed runtime manifests, so a host can pin which capabilities a document may use.
- Registered media types for CIML and IML documents.
- Native renderers: Swift and Kotlin generators.
- Non-EVM contract bindings. The binding `kind` already allows for them.
- Richer web rendering for `chart`, `map`, `diagram` and `timeline`, which currently show their label and children.
